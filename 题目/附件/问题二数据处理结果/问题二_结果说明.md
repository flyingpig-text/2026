# 问题二数据处理与优化结果说明

## 1. 数据来源与口径

- 电价：`题目/附件/附件1.xlsx`，单位 元/kWh，共 144 个 10 分钟点。
- 小区负载与光伏实际功率：`题目/附件/附件2.xlsx`，单位 kW，覆盖 2025-01-01 至 2025-12-31，共 365 天。
- 储能参数：`题目/C题.pdf` 附录 1。
- 未编造基础参数；所有通用参数均从 PDF 提取。

2025 年不是闰年，因此共有 365 天。把 144 个时刻点解释为
`0:00-0:10` 至 `23:50-24:00` 的自然时段。

单个 10 分钟时段的能量换算为：

```text
电量(kWh) = 功率(kW) × (10/60) h
          = 功率(kW) × 0.1666666667 h
```

## 4. 优化模型

每天 0:00 建立 144 个时段的混合整数线性规划。决策变量及其单位为：

- `x_t`：计划购电量，kWh；
- `e_t`：紧急购电量，kWh；
- `c_t`：储能充电量，kWh；
- `d_t`：储能放电量，kWh；
- `E_t`：时段末储电量，kWh；
- `s_t`：弃光量，kWh；
- `z_t`：充放电互斥变量，无量纲，取 0 或 1。

目标函数为：

```text
min Σ[电价_t × x_t + 5 × 电价_t × e_t]
```

主要约束为：

```text
电能平衡：
x_t + e_t + PV_t + d_t = Load_t + c_t + s_t

SOC递推：
E_t = E_(t-1) + η c_t - d_t / η

充放电功率：
0 ≤ c_t ≤ 5000 × (10/60)
0 ≤ d_t ≤ 5000 × (10/60)

充放电互斥：
c_t ≤ 833.333333 z_t
d_t ≤ 833.333333 (1-z_t)

SOC安全范围：
1200 ≤ E_t ≤ 10800 kWh

日循环条件：
E_(0:00) = E_(24:00) = 6000 kWh
```

其中 `η=0.9` 为充放电效率，单位为无量纲。

本模型采用“日循环储能”口径，即每天结束时恢复 0:00 的储电量，
避免通过跨日转移储能形成难以解释的免费电量。

物理含义：问题 2 在每天 0:00 制定计划时，附件 2 已给出当天逐 10 分钟的实际负荷

## 8. 灵敏度分析

对 4 个指定日期分别改变一个因素，保持其余因素为附件基准值。
表中每个数值是 4 个指定日期的平均日购电费。

| 因素 | 参数变化 | 平均日购电费/元 | 相对基准变化 |
|---|---:|---:|---:|
| 负荷 | -10% | 32424.946229 | -18.3001% |
| 负荷 | -5% | 35990.189031 | -9.3169% |
| 负荷 | 0% | 39687.883286 | 0.0000% |
| 负荷 | +5% | 43506.608501 | +9.6219% |
| 负荷 | +10% | 47395.598752 | +19.4208% |
| 光伏 | -10% | 42443.720194 | +6.9438% |
| 光伏 | -5% | 41036.380236 | +3.3978% |
| 光伏 | +5% | 38412.731936 | -3.2129% |
| 光伏 | +10% | 37209.032434 | -6.2459% |
| 充放电效率 | -10% | 42465.257061 | +6.9980% |
| 充放电效率 | -5% | 41075.395136 | +3.4961% |
| 充放电效率 | +5% | 38336.223391 | -3.4057% |
| 充放电效率 | +10% | 36965.257466 | -6.8601% |

灵敏度结论：

1. 购电费对负载变化最敏感，负载增加 10% 时平均日费用约增加 19.42%。
2. 光伏减少会提高购电费，光伏减少 10% 时平均日费用约增加 6.94%。
3. 储能效率提高可降低购电费，效率提高 10% 时平均日费用约下降 6.86%。
4. 在确定性实际数据下，紧急购电电价倍数从 3 倍变化到 7 倍，
   最优方案仍不需要紧急购电，因此费用不变。
