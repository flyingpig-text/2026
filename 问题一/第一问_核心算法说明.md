# 第一问核心算法函数说明

## 1. 模块结构

核心算法独立存放在 `code/first_question_core.py` 中。该模块只负责数学模型和求解逻辑，不读取 Excel、PDF，也不写出结果文件。

主程序 `code/第一问_MILP求解.py` 负责：

1. 读取附件和模板；
2. 生成数据预处理文件；
3. 调用核心算法模块；
4. 输出 `result1.xlsx`、分析表和图片。

## 2. 数据结构

### 2.1 `StorageSpec`

储能设备的物理参数集合。

输入字段：

| 字段 | 含义 | 单位 |
|---|---|---|
| `capacity_kwh` | 储能容量 | kWh |
| `power_kw` | 最大充放电功率 | kW |
| `initial_kwh` | 初始储电量 | kWh |
| `soc_min_kwh` | SOC安全下限 | kWh |
| `soc_max_kwh` | SOC安全上限 | kWh |
| `eta_charge` | 充电效率 | 无量纲 |
| `eta_discharge` | 放电效率 | 无量纲 |

输出：

一个经过合法性检查的不可变储能参数对象。

### 2.2 `EnergySeries`

优化模型使用的电价和电能序列。

| 字段 | 含义 | 单位 |
|---|---|---|
| `price_yuan_per_kwh` | 各时段电价 | 元/kWh |
| `load_energy_kwh` | 各时段负载电量 | kWh |
| `pv_energy_kwh` | 各时段光伏电量 | kWh |
| `net_energy_kwh` | 各时段净负荷电量 | kWh |

其中：

```text
load_energy_kwh(t) = load_kw(t) × Δt
pv_energy_kwh(t) = pv_kw(t) × Δt
net_energy_kwh(t) = load_energy_kwh(t) - pv_energy_kwh(t)
```

第一问中：

```text
Δt = 10/60 h = 1/6 h
```

### 2.3 `DispatchSolution`

单日购电和储能调度结果。

| 字段 | 含义 | 单位 |
|---|---|---|
| `grid_kwh` | 各时段购电量 | kWh |
| `charge_kwh` | 各时段充电量 | kWh |
| `discharge_kwh` | 各时段放电量 | kWh |
| `curtail_kwh` | 各时段弃光量 | kWh |
| `soc_kwh` | 每个时段结束后的储电量 | kWh |
| `objective_yuan` | 全天购电费 | 元 |
| `solver_status` | 求解器状态 | 文本 |
| `solver_backend` | 求解后端名称 | 文本 |
| `optimality_gap` | 相对最优性间隙 | 无量纲 |

## 3. 核心函数说明

### 3.1 `build_energy_series`

函数签名：

```python
build_energy_series(
    price_yuan_per_kwh: np.ndarray,
    load_kw: np.ndarray,
    pv_kw: np.ndarray,
    delta_t_h: float = DT_H,
) -> EnergySeries
```

作用：

将电价和功率序列转换为优化模型使用的电能序列。

输入：

| 输入 | 含义 | 单位 |
|---|---|---|
| `price_yuan_per_kwh` | 逐时段电价 | 元/kWh |
| `load_kw` | 逐时段小区负载功率 | kW |
| `pv_kw` | 逐时段光伏预测功率 | kW |
| `delta_t_h` | 时段长度 | h |

输出：

`EnergySeries`，包含电价、负载电量、光伏电量和净负荷电量。

核心公式：

```text
E_load(t) = P_load(t) × Δt
E_pv(t) = P_pv(t) × Δt
E_net(t) = E_load(t) - E_pv(t)
```

量纲校验：

```text
kW × h = kWh
```

### 3.2 `calculate_purchase_cost`

函数签名：

```python
calculate_purchase_cost(
    price_yuan_per_kwh: np.ndarray,
    grid_kwh: np.ndarray,
) -> float
```

作用：

独立复算全天购电费用。

输入：

| 输入 | 含义 | 单位 |
|---|---|---|
| `price_yuan_per_kwh` | 逐时段电价 | 元/kWh |
| `grid_kwh` | 逐时段购电量 | kWh |

输出：

全天购电费，单位为元。

公式：

```text
Z = Σ price_yuan_per_kwh(t) × grid_kwh(t)
```

该函数用于校验求解器目标函数值，避免目标函数编写或变量提取错误。

### 3.3 `solve_baseline_dispatch`

函数签名：

```python
solve_baseline_dispatch(
    series: EnergySeries,
    storage: StorageSpec,
) -> DispatchSolution
```

作用：

构造储能不动作的基准购电方案。

输入：

| 输入 | 含义 |
|---|---|
| `series` | 电价和净负荷电量序列 |
| `storage` | 储能参数，用于获取初始SOC |

输出：

基准 `DispatchSolution`。

计算规则：

```text
grid(t) = max(net_energy(t), 0)
charge(t) = 0
discharge(t) = 0
curtail(t) = max(-net_energy(t), 0)
SOC(t) = initial_kwh
```

物理含义：

储能不参与调节，剩余光伏电量被弃用，负载缺口全部由外网购电满足。

### 3.4 `build_milp_model`

函数签名：

```python
build_milp_model(
    series: EnergySeries,
    storage: StorageSpec,
) -> MilpModel
```

作用：

构造单日储能调度MILP的目标函数、变量上下界、整数变量和约束矩阵。

输入：

| 输入 | 含义 |
|---|---|
| `series` | 电价、负载电量、光伏电量和净负荷电量 |
| `storage` | 储能容量、功率、效率和SOC边界 |

输出：

`MilpModel`，包含：

| 输出字段 | 含义 |
|---|---|
| `objective` | 目标函数系数向量 |
| `integrality` | 变量整数属性 |
| `lower_bounds` | 变量下界 |
| `upper_bounds` | 变量上界 |
| `equality_matrix` | 等式约束系数矩阵 |
| `equality_rhs` | 等式约束右端项 |
| `inequality_matrix` | 不等式约束系数矩阵 |

决策变量顺序：

```text
[x(1:T), c(1:T), d(1:T), E(1:T), s(1:T), z(1:T)]
```

其中：

- `x`：购电量；
- `c`：充电量；
- `d`：放电量；
- `E`：时段末储电量；
- `s`：弃光量；
- `z`：充放电二进制状态。

目标函数：

```text
min Z = Σ price(t) × x(t)
```

电能平衡约束：

```text
x(t) + E_pv(t) + d(t)
= E_load(t) + c(t) + s(t)
```

储能递推约束：

```text
E(t) = E(t-1) + eta_c × c(t) - d(t) / eta_d
```

充放电互斥约束：

```text
c(t) <= Pmax × Δt × z(t)
d(t) <= Pmax × Δt × (1-z(t))
```

SOC与弃光约束：

```text
SOC_min <= E(t) <= SOC_max
0 <= s(t) <= E_pv(t)
```

### 3.5 `solve_milp_model`

函数签名：

```python
solve_milp_model(
    model: MilpModel,
    time_limit_s: float = 300.0,
    mip_rel_gap: float = 1e-9,
) -> tuple[np.ndarray, str, float | None]
```

作用：

调用 SciPy 的 `milp` 接口，由 HiGHS 分支定界求解器求解MILP。

输入：

| 输入 | 含义 | 单位 |
|---|---|---|
| `model` | `build_milp_model`输出 | 无 |
| `time_limit_s` | 求解时间上限 | s |
| `mip_rel_gap` | 相对最优性间隙 | 无量纲 |

输出：

```text
(原始解向量, 求解状态, 最优性间隙)
```

若求解器无法得到可行解，函数抛出异常，不返回伪结果。

### 3.6 `extract_dispatch_solution`

函数签名：

```python
extract_dispatch_solution(
    series: EnergySeries,
    storage: StorageSpec,
    model: MilpModel,
    raw_solution: np.ndarray,
    solver_status: str,
    optimality_gap: float | None,
) -> DispatchSolution
```

作用：

从MILP原始变量向量中提取购电、充放电、弃光和SOC结果。

输入：

| 输入 | 含义 |
|---|---|
| `series` | 电力序列 |
| `storage` | 储能参数 |
| `model` | 变量切片和约束结构 |
| `raw_solution` | HiGHS返回的完整解向量 |
| `solver_status` | 求解状态 |
| `optimality_gap` | 最优性间隙 |

输出：

`DispatchSolution`。

解提取公式：

```text
SOC(0) = initial_kwh
SOC(t) = SOC(t-1)
       + eta_c × charge(t)
       - discharge(t) / eta_d
```

购电费用重新计算：

```text
objective_yuan = Σ price(t) × grid(t)
```

### 3.7 `solve_daily_dispatch_milp`

函数签名：

```python
solve_daily_dispatch_milp(
    series: EnergySeries,
    storage: StorageSpec,
    time_limit_s: float = 300.0,
    mip_rel_gap: float = 1e-9,
) -> DispatchSolution
```

作用：

封装完整求解流程：

```text
构建MILP模型
→ HiGHS求解
→ 提取物理变量
→ 复算购电费用
```

输入和输出与前述函数一致，适合作为论文算法主入口。

### 3.8 `validate_dispatch_solution`

函数签名：

```python
validate_dispatch_solution(
    series: EnergySeries,
    storage: StorageSpec,
    solution: DispatchSolution,
    tolerance: float = 1e-4,
) -> dict[str, float]
```

作用：

检查优化结果是否满足物理约束。

检查项：

- 电能平衡残差；
- SOC递推残差；
- 供电不足累计量；
- 最大充电功率；
- 最大放电功率；
- SOC上下限；
- 首末SOC误差；
- 同时充放电指标。

输出：

各检查项数值组成的字典；若任一检查超过容差，抛出异常。

### 3.9 `aggregate_blocks`

函数签名：

```python
aggregate_blocks(
    values_kwh: np.ndarray,
    block_size: int = 24,
) -> list[float]
```

作用：

将10分钟结果聚合为4小时结果。

输入：

| 输入 | 含义 | 单位 |
|---|---|---|
| `values_kwh` | 10分钟电量序列 | kWh |
| `block_size` | 每个4小时块的10分钟时段数 | 无量纲 |

输出：

长度为6的4小时电量列表，单位为kWh。

聚合公式：

```text
E_block(k) = Σ E_t
```

## 5. 适合论文算法章节的简短表述

第一问采用确定性单日混合整数线性规划模型。首先将附件中的10分钟功率数据按 `Δt=1/6 h` 转换为电量，并构造净负荷序列；随后以购电、充电、放电、SOC、弃光和充放电状态为决策变量，建立包含电能平衡、SOC递推、功率上限、SOC安全边界、充放电互斥和首末SOC相等的约束；最后调用HiGHS分支定界算法求解，并从解向量中提取购电计划和储能调度计划。求解后通过电能平衡复算、SOC递推复算、功率边界检查和购电费用独立复算验证结果的物理可行性和数值一致性。
