# 问题二两阶段随机规划函数说明

本文档对应 `problem2_stochastic.py`，说明带补偿两阶段随机规划的函数接口、
输入输出、单位、公式和约束。数据读取与文件导出由 `problem2_run.py` 完成。
`problem2_adaptive.py` 在此基础上实现实际运行时只锁定计划购电、动态充放电
和未来价值执行，并把未利用供能惩罚、CVaR尾部风险和时段级购电风险下限纳入
日前规划。

## 1. 信息集与决策结构

第 \(d\) 天计划阶段的可用信息为：

\[
\mathcal I_d
=
\{L_{d-k,t},G_{d-k,t},\hat G_{d-k,t}\mid k\ge1\}.
\]

模型将每天划分为 \(T=144\) 个 10 分钟时段：

\[
\Delta t=\frac{10}{60}=\frac{1}{6}\ \text{h}.
\]

第一阶段决策：

\[
X_{d,t}^{DA},C_{d,t},D_{d,t},E_{d,t},z_{d,t}.
\]

第二阶段决策：

\[
e_{d,t}^{\omega},S_{d,t}^{\omega}.
\]

第一阶段变量在所有情景下保持一致，第二阶段变量按情景分别确定。

| 函数 | 目的 |

| `generate_historical_scenarios` | 由历史误差生成负荷和光伏情景及概率 |
| `build_stochastic_model` | 构造两阶段随机规划稀疏矩阵 |
| `solve_stochastic_plan` | 求解随机 LP/MILP |
| `solve_rolling_stochastic_plan` | 逐日滚动随机规划，正式主结果求解器 |
| `validate_stochastic_solution` | 复核情景平衡、SOC、功率和互斥约束 |
| `realize_stochastic_plan` | 用真实负荷和光伏结算实际应急电量 |
| `evaluate_plan_under_scenarios` | 固定第一阶段计划后评价期望费用 |
| `run_extended_stochastic_sensitivity` | 对新模型做扩展单因素灵敏度分析 |

## 3. `generate_historical_scenarios`

### 3.1 函数签名

```python
generate_historical_scenarios(
    load_actual_kwh: np.ndarray,
    pv_actual_kwh: np.ndarray,
    reference_load_kwh: np.ndarray,
    reference_pv_kwh: np.ndarray,
    *,
    n_scenarios: int = 5,
    lookback_days: int = 30,
    error_scale: float = 1.0,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]
```

### 3.2 输入

| 参数 | 维度 | 单位 | 含义 |
|---|---:|---|---|
| `load_actual_kwh` | \((365,144)\) | kWh | 附件 2 实际负荷 |
| `pv_actual_kwh` | \((365,144)\) | kWh | 附件 2 实际光伏 |
| `reference_load_kwh` | \((144,)\) | kWh | 附件1参考日负荷，用于首日递推 |
| `reference_pv_kwh` | \((144,)\) | kWh | 附件1参考日光伏，用于首日递推 |
| `n_scenarios` | 标量 | 个 | 每天情景数 |
| `lookback_days` | 标量 | 天 | 历史误差回看窗口 |
| `error_scale` | 标量 | 无量纲 | 预测误差缩放系数 |

负荷点预测由 `build_point_forecasts` 使用日电量水平、同类型日形状和
日类型切换倍率递推；光伏点预测使用截至前一日的最近 3 个实际日平均。
负荷与光伏误差按同一历史日成对抽取，不使用当天及未来实际值。

### 3.3 输出

返回：

\[
L^{\omega}_{d,t}\in\mathbb R^{365\times S\times144},
\quad
G^{\omega}_{d,t}\in\mathbb R^{365\times S\times144},
\quad
p_{d,\omega}\in\mathbb R^{365\times S}.
\]

其中：

\[
p_{d,\omega}>0,\qquad
\sum_{\omega=1}^{S}p_{d,\omega}=1.
\]

情景构造为：

\[
L^{\omega}_{d,t}
=
\max\left(0,\hat L_{d,t}
+\rho\varepsilon^{L}_{\omega,t}\right),
\]

\[
G^{\omega}_{d,t}
=
\max\left(0,\hat G_{d,t}
+\rho\varepsilon^{G}_{\omega,t}\right).
\]

## 4. `build_stochastic_model`

### 4.1 函数签名

```python
build_stochastic_model(
    load_scenarios_kwh: np.ndarray,
    pv_scenarios_kwh: np.ndarray,
    scenario_probabilities: np.ndarray,
    price_144_yuan_per_kwh: np.ndarray,
    storage: StorageParameters,
    *,
    emergency_multiplier: float = 5.0,
    initial_soc_kwh: float | None = None,
    terminal_soc_value_yuan_per_kwh: float = 0.0,
    relax_binary: bool = False,
    soc_final_policy: str = "free",
) -> StochasticMILPModel
```

### 4.2 目标函数

\[
\min Z
=
\sum_{d,t}\pi_tX_{d,t}^{DA}
+
\sum_{\omega}p_{\omega}
\sum_{d,t}5\pi_te_{d,t}^{\omega}.
\]

第一项为计划购电费用，第二项为情景期望紧急购电费用。题目没有要求日末
库存续存价值，`terminal_soc_value_yuan_per_kwh` 默认取 0；若显式启用，
可取 `v = mean(0:00--5:00电价) / eta`，单位为元/kWh。

自适应规划扩展在此基础上增加：

\[
J^+ =
J
+
\alpha_U E\left[\sum_t U_{t,\omega}\right]
+
\alpha_C E\left[\sum_t(C_{t,\omega}+D_{t,\omega})\right]
+
\lambda \operatorname{CVaR}_{\beta}(K_b)
\]

其中 \(\alpha_U\) 为未利用供能错配惩罚，\(\alpha_C\) 为循环正则项，
\(K_b\) 为情景紧急购电费用，\(\operatorname{CVaR}_{\beta}\) 用于约束高价缺电尾部。

### 4.3 情景电能平衡

\[
X_{d,t}^{DA}
+G_{d,t}^{\omega}\Delta t
+D_{d,t}
+e_{d,t}^{\omega}
=
L_{d,t}^{\omega}\Delta t
+C_{d,t}
+S_{d,t}^{\omega}.
\]

### 4.4 第一阶段 SOC 递推

\[
E_{d,t}
=
E_{d,t-1}
+\eta C_{d,t}
-\frac{D_{d,t}}{\eta}.
\]

### 4.5 功率和互斥约束

\[
0\le C_{d,t}\le833.333333,
\qquad
0\le D_{d,t}\le833.333333,
\]

\[
C_{d,t}\le833.333333z_{d,t},
\qquad
D_{d,t}\le833.333333(1-z_{d,t}),
\]

\[
z_{d,t}\in\{0,1\}.
\]

这里 \(833.333333\) 的单位为 kWh：

\[
5000\ \text{kW}\times\frac{1}{6}\ \text{h}
=833.333333\ \text{kWh}.
\]

### 4.6 输出规模

当 \(D=365\)、\(T=144\)、\(S=5\) 时：

\[
n=DT=52560,
\]

\[
\text{变量数}=5n+2Sn=788400,
\]

\[
\text{第一阶段SOC约束}=n=52560,
\]

\[
\text{情景电能平衡约束}=Sn=262800,
\]

\[
\text{充放电互斥约束}=2n=105120.
\]

## 5. `solve_stochastic_plan`

```python
solve_stochastic_plan(
    load_scenarios_kwh,
    pv_scenarios_kwh,
    scenario_probabilities,
    price_144_yuan_per_kwh,
    storage,
    *,
    emergency_multiplier=5.0,
    initial_soc_kwh=None,
    relax_binary=False,
    soc_final_policy="free",
    time_limit_s=900.0,
    tie_break_epsilon=1e-6,
    logger=None,
) -> StochasticSolution
```

`relax_binary=True` 时先求随机 LP 下界。由于连续松弛可能产生
\(C_{d,t},D_{d,t}\) 同时为正的退化解，函数用一个很小的正则项
\(\varepsilon(C_{d,t}+D_{d,t})\) 选取无同时充放电的等价 LP 解；
最终费用仍按原始目标函数重新计算。若正则化后仍不满足互斥，则应调用
`relax_binary=False` 执行随机 MILP。

## 6. `validate_stochastic_solution`

复核以下指标：

\[
r_{d,t}^{\omega}
=
X_{d,t}^{DA}
+G_{d,t}^{\omega}\Delta t
+D_{d,t}
+e_{d,t}^{\omega}
-L_{d,t}^{\omega}\Delta t
-C_{d,t}
-S_{d,t}^{\omega}.
\]

\[
\text{Deficit}_{d,t}^{\omega}
=
\max\left(
0,
L_{d,t}^{\omega}\Delta t+C_{d,t}
-X_{d,t}^{DA}
-G_{d,t}^{\omega}\Delta t-D_{d,t}
\right).
\]

检查：

\[
e_{d,t}^{\omega}\approx\text{Deficit}_{d,t}^{\omega},
\qquad
0\le S_{d,t}^{\omega}\le G_{d,t}^{\omega}\Delta t,
\]

\[
1200\le E_{d,t}\le10800,
\qquad
\max_t\min(C_{d,t},D_{d,t})\approx0.
\]

## 7. `realize_stochastic_plan`

用附件 2 的真实负荷和光伏计算最终应急电量：

\[
e_{d,t}^{real}
=
\max\left(
0,
L_{d,t}\Delta t+C_{d,t}
-X_{d,t}^{DA}
-G_{d,t}\Delta t-D_{d,t}
\right).
\]

实际结算费用为：

\[
Z^{real}
=
\sum_{d,t}\pi_tX_{d,t}^{DA}
+5\sum_{d,t}\pi_te_{d,t}^{real}.
\]

该结果用于生成 `result2.xlsx` 中的实际紧急购电时段表。

## 8. `evaluate_plan_under_scenarios`

固定第一阶段计划 \((X,C,D)\) 后，在情景集合上评价：

\[
Z_{EEV}
=
\sum_{d,t}\pi_tX_{d,t}^{DA}
+\sum_{\omega}p_{\omega}
\sum_{d,t}5\pi_t\text{Deficit}_{d,t}^{\omega}.
\]

该函数用于随机解价值分析：

\[
VSS=Z_{EEV}-Z_{stoch}.
\]

如果确定性点预测方案在某个情景下要求弃光电量超过该情景光伏上限，
函数返回“情景不可行”，不把无穷大或未约束的数值结果作为 VSS。

## 9. `solve_rolling_stochastic_plan`

```python
solve_rolling_stochastic_plan(
    load_scenarios_kwh,
    pv_scenarios_kwh,
    scenario_probabilities,
    price_144_yuan_per_kwh,
    storage,
    *,
    emergency_multiplier=5.0,
    initial_soc_kwh=None,
    terminal_soc_value_yuan_per_kwh=0.0,
    soc_final_policy="free",
    tie_break_epsilon=1e-6,
    time_limit_s=60.0,
    logger=None,
) -> StochasticSolution
```

该函数按日期顺序逐日求解。第 \(d\) 天的优化使用第 \(d\) 天情景集合，
并将第 \(d-1\) 天得到的时段末 SOC 作为第 \(d\) 天初始 SOC。该函数是
新模型的正式主求解器，不是全年一次性优化后的附加回测。

运行入口使用：

```powershell
python problem2_run.py --model stochastic
```

输出文件为 `tables/逐日滚动主结果.csv`。

## 10. `run_extended_stochastic_sensitivity`

对指定日期重新求解单日两阶段随机模型，分析以下因素：

| 因素 | 取值 |
|---|---|
| 负荷规模 | 0.9、1.0、1.1 |
| 光伏规模 | 0.9、1.0、1.1 |
| 电价水平 | 0.9、1.0、1.1 |
| 峰谷价差 | 0.8、1.0、1.2 |
| 情景数量 | 3、5、7 |
| 历史回看天数 | 15、30、45 |
| 预测误差缩放 | 0.8、1.0、1.2 |
| 紧急电价倍数 | 3、5、7 |
| 充放电效率 | 0.81、0.90、0.99 |
| 续存价值倍率 | 0、1、2 |
| 初始储电量 | 5000、6000、7000 kWh |

除“初始储电量”情景外，灵敏度模型使用全年主模型在对应指定日期 0:00
的 SOC，而不是固定使用 6000 kWh。

输出包括：

- 期望总购电费；
- 实际结算总购电费；
- 计划购电量；
- 期望紧急购电量；
- 实际紧急购电量；
- 最大同时充放电量。

所有电量单位为 kWh，功率单位为 kW，费用单位为元，电价单位为元/kWh。
