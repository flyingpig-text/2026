# 问题四：波动电价下微网当天购电策略的完整推导与检验

本文对应第四问，给出 `result4-2.xlsx` 和 `result4-3.xlsx` 两个模型从符号、情景构造、日前优化、日内调整到实时执行的完整数学推导，并补充假设、失效条件和检验方法。

---

## 1. 符号、时间尺度和基本换算

设每天划分为

\[
T=144,\qquad
\Delta t=\frac{10}{60}=\frac16\ \text{h}.
\]

记第 \(d\) 天第 \(t\) 个 10 分钟时段为 \(t=1,\ldots,144\)。正式输出日期为

\[
\mathcal D=\{2025\text{-}02\text{-}01,\ldots,2025\text{-}12\text{-}31\},
\]

共 334 天。2025 年 1 月仅用于生成历史情景和储能预热。

主要符号如下：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(\pi_{d,t}\) | 第 \(d\) 天第 \(t\) 时段实时电价 | 元/kWh |
| \(g_{d,t}\) | 0:00 制定的计划购电量 | kWh |
| \(q_{d,t}\) | 预报点更新后的最终购电量，仅问题三有 | kWh |
| \(c_{d,t}\) | 储能充电量 | kWh |
| \(d_{d,t}\) | 储能放电量 | kWh |
| \(e_{d,t}\) | 紧急购电量 | kWh |
| \(s_{d,t}\) | 弃光电量 | kWh |
| \(E_{d,t}\) | 第 \(t\) 时段末储电量 | kWh |
| \(L_{d,t}\) | 小区负荷电量 | kWh |
| \(W_{d,t}\) | 光伏发电电量 | kWh |
| \(\eta\) | 充放电效率 | 无量纲 |

原始附件 2 的负荷和光伏功率为 kW，附件 3 的光伏预报为 kW，附件 4 的电价为元/kWh。所有功率先转换为电量：

\[
L_{d,t}=P^L_{d,t}\Delta t,\qquad
W_{d,t}=P^W_{d,t}\Delta t.
\]

物理意义：能量平衡、储能递推和费用计算必须统一到 kWh，不能把 kW 与 kWh 直接相加。

## 2. 储能设备约束

储能最大容量为

\[
E_{\text{cap}}=12000\ \text{kWh}.
\]

安全运行范围为

\[
1200\le E_{d,t}\le10800\ \text{kWh}.
\]

最大充放电功率为

\[
P_{\max}=5000\ \text{kW}.
\]

对应单时段最大充放电电量为

\[
M=P_{\max}\Delta t=5000\times\frac16=833.333\ \text{kWh}.
\]

因此

\[
0\le c_{d,t}\le M,\qquad
0\le d_{d,t}\le M.
\]

充放电效率为

\[
\eta=0.9.
\]

储能递推为

\[
E_{d,t}
=
E_{d,t-1}
+
\eta c_{d,t}
-
\frac{d_{d,t}}{\eta}.
\]

物理意义：充入电池的内部电量只有 \(\eta c_{d,t}\)；向外部提供 \(d_{d,t}\) 需要消耗内部电量 \(d_{d,t}/\eta\)。

初始条件和跨日连续性为

\[
E_{2025\text{-}01\text{-}01,0}=6000,
\]

\[
E_{d,0}=E_{d-1,T}.
\]

物理意义：前一天实际日末 SOC 必须传递给次日 0:00，不能每天重新固定为 6000 kWh。

充放电互斥可采用显式二元变量：

\[
c_{d,t}\le Mz_{d,t},\qquad
d_{d,t}\le M(1-z_{d,t}),\qquad
z_{d,t}\in\{0,1\},
\]

或在主线性模型中使用凸包松弛：

\[
c_{d,t}+d_{d,t}\le M.
\]

物理意义：避免同一时段同时有效充电和放电，产生无意义的能量对冲。

## 3. 波动电价的情景构造

问题四与问题二、问题三的关键区别是，外网电价来自附件 4，随时间实时波动。由于题目没有提供电价预测文件，模型应利用附件 4 的历史实际价格构造价格情景。

设 \(\Omega_d\) 为第 \(d\) 天的联合情景集合，情景概率满足

\[
\sum_{\omega\in\Omega_d}p_\omega=1,\qquad p_\omega>0.
\]

推荐采用历史同日配对采样：

\[
(L_{d,t}^\omega,W_{d,t}^\omega,\pi_{d,t}^\omega)
=
(
\widehat L_{d,t}+\varepsilon_{\tau,t}^L,
\widehat W_{d,t}+\varepsilon_{\tau,t}^W,
\pi_{\tau,t}
),
\]

其中 \(\tau\) 为同一历史日期，\(\varepsilon_{\tau,t}^L,\varepsilon_{\tau,t}^W\) 为历史负荷和光伏预测误差，\(\pi_{\tau,t}\) 为该历史日的实际价格曲线。

物理意义：负荷、光伏和价格在现实中可能由同一批天气、日期和市场条件共同驱动。按同一历史日期成对采样，可以保留三者之间的相关性，避免把价格独立抽样后破坏联合分布。

若希望体现日内价格预测的更新能力，还可以构造条件价格情景：

\[
\pi_{d,t}^\omega
=
\pi_{d,s}^{\text{actual}}
+
(\pi_{\tau,t}-\pi_{\tau,s}),
\]

其中 \(s\) 为当前已观察到的时段。物理意义：在 6:00、12:00、18:00 调整时，已看到当天截至 \(s\) 的实际价格，未来价格用历史同时段的价格增量围绕当前水平外推。

## 4. `result4-2`：波动电价下问题二的完整模型

### 4.1 信息集和非预期性

第 \(d\) 天 0:00 制定计划时，可用信息为

\[
\mathcal F_d
=
\{
L_{\tau,t},W_{\tau,t},\pi_{\tau,t}:\tau<d
\}
\cup
\{\text{历史预测误差}\}.
\]

物理意义：0:00 不能看到当天未来的实际负荷、实际光伏和实际价格，只能使用历史数据形成情景。

\(g_t\) 在 0:00 制定后当天锁定：

\[
g_t=g_t^*,\qquad t=1,\ldots,144.
\]

储能动作 \(c_t,d_t\) 在实际运行阶段根据实时观测调整。

### 4.2 0:00 日前两阶段随机规划目标

计划购电量 \(g_t\) 是所有情景共享的第一阶段决策，储能、紧急购电和弃光按情景追索。0:00 目标函数为

\[
\min_{g_t}
\sum_{t=1}^{144}
\bar\pi_t g_t
+
\sum_{\omega\in\Omega_d}p_\omega
\sum_{t=1}^{144}
5\pi_{t,\omega}e_{t,\omega}
-
\lambda
\sum_{\omega\in\Omega_d}p_\omega E_{T,\omega},
\]

其中

\[
\bar\pi_t
=
\sum_{\omega\in\Omega_d}p_\omega\pi_{t,\omega}.
\]

物理意义：

1. \(g_t\) 是 0:00 承诺购买量，但未来实际电价尚未确定，因此计划购电成本只能用期望价格 \(\bar\pi_tg_t\) 衡量；
2. 紧急购电按情景中的实时价格 5 倍计费；
3. \(-\lambda E_T\) 是日末库存续存价值，避免模型为了降低当日费用而把电池过度放空。

### 4.3 情景功率平衡

每个情景、每个时段必须满足

\[
g_t
+
W_{t,\omega}
+
d_{t,\omega}
+
e_{t,\omega}
=
L_{t,\omega}
+
c_{t,\omega}
+
s_{t,\omega},
\qquad
\forall\omega,t.
\]

物理意义：左侧是计划购电、光伏、放电和紧急购电；右侧是负荷、充电和弃光。任一情景下都不能出现供电缺口。

### 4.4 储能递推与边界

\[
E_{t,\omega}
=
E_{t-1,\omega}
+
\eta c_{t,\omega}
-
\frac{d_{t,\omega}}{\eta},
\]

\[
E_{0,\omega}=E_{d-1,T}^{\text{actual}},
\]

\[
1200\le E_{t,\omega}\le10800,
\]

\[
0\le c_{t,\omega},d_{t,\omega}\le M,
\]

\[
c_{t,\omega}+d_{t,\omega}\le M,
\]

\[
0\le s_{t,\omega}\le W_{t,\omega},
\qquad
e_{t,\omega}\ge0,
\qquad
g_t\ge0.
\]

物理意义：每个情景都必须满足储能安全、功率上限和弃光不超过光伏发电量等物理条件。

### 4.5 日前阶段求解算法

上述模型对每个 \(d\) 是一个线性规划或小型混合整数线性规划。求解后只保存共同决策：

\[
g_t^*=\arg\min
\left[
\sum_t\bar\pi_tg_t
+
\sum_\omega p_\omega\sum_t5\pi_{t,\omega}e_{t,\omega}
-
\lambda\sum_\omega p_\omega E_{T,\omega}
\right].
\]

物理意义：日前阶段并不需要确定每个情景的充放电轨迹，只需要确定对所有情景都稳健的计划购电量。

### 4.6 实际运行与实时电价执行

0:00 后 \(g_t\) 已固定。定义实际净缺口：

\[
r_t
=
L_t^{\text{actual}}
-
W_t^{\text{actual}}
-
g_t.
\]

物理意义：\(r_t>0\) 表示计划购电和实际光伏不足以覆盖负荷，需要储能放电或紧急购电；\(r_t\le0\) 表示当前有光伏富余，应优先充电。

当 \(r_t\le0\) 时，充电量为

\[
c_t
=
\min\left(
-r_t,
M,
\frac{E_{\max}-E_{t-1}}{\eta}
\right),
\]

\[
d_t=0,\qquad e_t=0,
\]

\[
s_t=\max(0,-r_t-c_t).
\]

物理意义：富余光伏优先充入储能，超过充电功率或 SOC 上限的部分才弃光。

当 \(r_t>0\) 时，放电上界为

\[
d_t^{\max}
=
\min\left(
r_t,
M,
\eta(E_{t-1}-E_{\min})
\right).
\]

候选放电量由下式决定：

\[
d_t
=
\arg\min_{0\le d\le d_t^{\max}}
\left[
5\pi_t^{\text{actual}}(r_t-d)
+
V_{t+1}
\left(
E_{t-1}-\frac d\eta
\right)
\right].
\]

随后

\[
e_t=\max(0,r_t-d_t),
\]

\[
E_t
=
E_{t-1}
+
\eta c_t
-
\frac{d_t}{\eta}.
\]

物理意义：现在放电可以减少当前 5 倍紧急购电费用，但会降低未来可用储能。模型需要在当前节省和未来机会成本之间权衡。

### 4.7 实时价格下的未来价值函数

末端边界为

\[
V_{T+1}(E)=-\lambda E.
\]

对 \(t=T,T-1,\ldots,1\) 逆推：

\[
V_t(E)
=
\min_{c,d}
\mathbb E_\omega
\left[
5\pi_{t,\omega}
(R_{t,\omega}-d)^+
+
V_{t+1}
\left(
E+\eta c-\frac d\eta
\right)
\right],
\]

其中

\[
R_{t,\omega}
=
L_{t,\omega}-W_{t,\omega}-g_t.
\]

物理意义：\(V_t(E)\) 表示在当前 SOC 为 \(E\) 时，从时段 \(t\) 运行到日末的期望最小费用。问题四中 \(V_t\) 同时依赖负荷、光伏和实时价格情景，因此比问题二增加一个价格状态维度。

## 5. `result4-3`：波动电价下问题三的完整模型

### 5.1 决策时点

问题三保留四个决策时点：

\[
s\in\{0,6,12,18\}.
\]

对应时段索引可写为

\[
\tau_0=0,\quad
\tau_6=36,\quad
\tau_{12}=72,\quad
\tau_{18}=108.
\]

物理意义：

1. 0:00 制定 \(g_t\)；
2. 6:00、12:00、18:00 根据最新光伏预报和已观察价格更新 \(q_t\)；
3. 储能充放电逐 10 分钟实时调整。

### 5.2 0:00 计划购电模型

0:00 目标函数为

\[
\min_{g_t}
\sum_{t=1}^{144}
\bar\pi_t g_t
+
\sum_\omega p_\omega
\sum_{t=1}^{144}
5\pi_{t,\omega}e_{t,\omega}
-
\lambda
\sum_\omega p_\omega E_{T,\omega},
\]

约束与问题二的日前模型相同。物理意义：0:00 只确定一个对所有情景稳健的基础购电计划 \(g_t\)。

求解后令初始最终购电量为

\[
q_t=g_t,\qquad t=1,\ldots,144.
\]

### 5.3 预报点调整购电模型

在 \(s=6,12,18\)，只更新未来尚未执行的一个 36 时段块，记为

\[
\mathcal B_s
=
\left\{
\frac{s}{\Delta t}+1,\ldots,
\frac{s+6}{\Delta t}
\right\}.
\]

定义上调量和下调量：

\[
\Delta_t^+=\max(q_t-g_t,0),
\qquad
\Delta_t^-=\max(g_t-q_t,0).
\]

线性化为

\[
q_t-g_t=\Delta_t^+-\Delta_t^-,
\]

\[
\Delta_t^+\ge0,\qquad
\Delta_t^-\ge0.
\]

物理意义：上调量表示实际购电量超过计划的部分，下调量表示低于计划的部分，二者分别对应不同的价格惩罚。

调整阶段目标函数为

\[
\min_{q_t}
\sum_{t\in\mathcal B_s}
\bar\pi_{t|s}
\left(
1.5\Delta_t^+
+0.5\Delta_t^-
\right)
+
\sum_\omega p_\omega
\sum_{t\in\mathcal B_s}
5\pi_{t,\omega}e_{t,\omega}
-
\lambda
\sum_\omega p_\omega E_{|\mathcal B_s|,\omega},
\]

其中

\[
\bar\pi_{t|s}
=
\mathbb E[\pi_{t,\omega}\mid\mathcal F_s].
\]

物理意义：

1. 下调原计划中未执行的部分，仍要按期望实时价格的 50% 支付违约费用；
2. 上调部分按期望实时价格的 150% 购买；
3. 紧急购电按情景价格 5 倍计算；
4. 日末库存价值用于避免局部窗口短视。

该阶段的约束与日前模型一致，但初始 SOC 使用当前实际 SOC：

\[
E_{0,\omega}^{\mathcal B_s}=E_s^{\text{actual}}.
\]

物理意义：调整购电时，储能状态已经随此前真实运行发生改变，不能回到 0:00 的虚拟状态。

### 5.4 实时储能执行

调整完成后，固定 \(q_t\)。在时刻 \(t\) 定义实际净缺口：

\[
\widetilde R_t
=
L_t^{\text{actual}}
-
W_t^{\text{actual}}
-
q_t.
\]

当 \(\widetilde R_t\le0\) 时：

\[
c_t=
\min\left(
-\widetilde R_t,
M,
\frac{E_{\max}-E_{t-1}}{\eta}
\right),
\]

\[
d_t=0,\qquad e_t=0,\qquad
s_t=\max(0,-\widetilde R_t-c_t).
\]

当 \(\widetilde R_t>0\) 时：

\[
d_t^{\max}
=
\min\left(
\widetilde R_t,
M,
\eta(E_{t-1}-E_{\min})
\right),
\]

\[
d_t
=
\arg\min_{0\le d\le d_t^{\max}}
\left[
5\pi_t^{\text{actual}}(\widetilde R_t-d)
+
V_{t+1}
\left(
E_{t-1}-\frac d\eta
\right)
\right],
\]

\[
e_t=\max(0,\widetilde R_t-d_t),
\]

\[
E_t
=
E_{t-1}
+
\eta c_t
-
\frac{d_t}{\eta}.
\]

物理意义：储能只在固定购电量 \(q_t\) 之外补偿实际偏差，并且当前时段的实时电价可以直接观察到，未来价格仍通过 \(V_{t+1}\) 的情景期望刻画。

### 5.5 完整算法流程

1. 读取附件 2、附件 3、附件 4 和储能参数；
2. 用历史负荷、光伏误差和附件 4 历史价格构造联合情景；
3. 在 0:00 求解日前随机规划，只保存 \(g_t\)；
4. 令 \(q_t=g_t\)；
5. 在 0:00 至 6:00 按实际数据执行储能；
6. 到 6:00，用最新光伏预报、已观察实际价格和条件价格情景更新 \(q_t\)；
7. 在 12:00、18:00 重复步骤 6；
8. 每个 10 分钟用实际负荷、实际光伏、实际价格和固定 \(q_t\) 更新充放电与 SOC；
9. 日末把实际 SOC 传递给次日；
10. 按附件 4 实际价格计算最终费用；
11. 按 `result4-3.xlsx` 模板输出结果。

## 7. 模型前提与假设

### 7.1 时间与计量假设

1. 每天离散为 144 个 10 分钟时段，时段内负荷、光伏、电价近似恒定；
2. 所有功率乘 \(\Delta t\) 后精确转换为电量；
3. 时间标签按区间末端理解，`0:00+1` 表示 24:00；
4. 不考虑数据缺失、时区错位和测量延迟。

### 7.2 价格与情景假设

1. 附件 4 历史实际价格能够代表未来价格波动分布；
2. 价格情景与负荷、光伏误差按同一历史日期配对，保留相关性；
3. 价格误差在短窗口内具有条件平稳性；
4. 情景概率相等，或用历史频率估计；
5. 当前时段的实际价格在实时执行时能够被准确观测；
6. 未来时段的实际价格在决策时不可知，只能使用情景期望；
7. 附件 3 的整点光伏预报在对应 6 个 10 分钟区间内保持不变。

### 7.3 储能与电网假设

1. 充放电效率恒为 0.9，不随 SOC、功率和温度变化；
2. SOC 安全范围为 1200 至 10800 kWh；
3. 最大充放电功率为 5000 kW；
4. 不考虑自放电、老化、温度、爬坡和循环寿命；
5. 同一时段不进行有效的同时充放电；
6. 不考虑线损、网络潮流、电压和传输容量约束；
7. 外部电网可以无限提供常规购电和紧急购电；
8. 不向外部电网售电，弃光无收益且无额外惩罚。

### 7.4 决策与费用假设

1. 问题二只有 \(g_t\) 和实时储能，没有 \(q_t\)；
2. 问题三中 \(g_t\) 只在 0:00 确定，\(q_t\) 只在 6:00、12:00、18:00 更新未来未执行时段；
3. 下调部分按实时价格的 0.5 倍支付违约费；
4. 上调部分按实时价格的 1.5 倍购买；
5. 紧急购电按实时价格的 5 倍购买；
6. 目标函数采用风险中性期望费用；
7. 实际结算使用附件 4 的真实价格；
8. 终端库存价值 \(\lambda\) 是滚动边界近似，不代表实际售电收入。

## 8. 模型失效条件

1. 价格机制发生结构性变化，例如市场规则、峰谷价差或紧急购电倍数改变，历史价格样本不再代表未来；
2. 出现历史未覆盖的价格尖峰、连续高价或极低价格，情景尾部不足；
3. 负荷、光伏和价格之间的相关性发生改变，同日配对采样失效；
4. 价格误差非平稳，季节或天气导致的分布漂移未被条件情景捕捉；
5. 情景数量过少，无法覆盖极端低光伏、高负荷和高价格同时发生的尾部风险；
6. 0:00 或预报点的决策使用了未来实际价格，违反非预期约束；
7. 储能效率、容量或功率发生显著变化，或存在爬坡、温度和寿命约束；
8. 外部电网出现最大购电功率、停电或紧急购电容量限制；
9. 附件 4 价格与附件 2 负荷光伏时间错位，导致错误配对；
10. 线性松弛导致同时充放电，或 SOC 网格过粗使价值函数失真；
11. 日末实际 SOC 没有正确传递到次日；
12. 输出文件的日期、时段或工作表结构与官方模板不一致。

## 9. 模型检验方法与合理性判断

### 9.1 量纲与单位检验

检查全部输入输出是否满足：

\[
[\text{功率}]\times[\text{h}]=[\text{kWh}],
\qquad
[\text{电价}]\times[\text{kWh}]=[\text{元}].
\]

物理意义：防止功率与电量直接相加、费用单位错乱。

### 9.2 能量平衡检验

对每个实际时段计算残差：

\[
r_t
=
q_t
+
W_t^{\text{actual}}
+
d_t
+
e_t
-
L_t^{\text{actual}}
-
c_t
-
s_t.
\]

要求

\[
\max_{d,t}|r_{d,t}|\le10^{-4}\ \text{kWh}.
\]

对 `result4-2`，上式中的 \(q_t\) 替换为 \(g_t\)。物理意义：确认没有漏记或重复记录购电、光伏、充放电、弃光和紧急购电。

### 9.3 SOC 递推与边界检验

逐时段反推 SOC：

\[
\widehat E_t
=
E_{t-1}
+
\eta c_t
-
\frac{d_t}{\eta}.
\]

要求

\[
\max_t|\widehat E_t-E_t|\le10^{-4},
\]

\[
1200\le E_t\le10800,
\]

\[
E_{d,0}=E_{d-1,T}.
\]

物理意义：确认储能状态由充放电正确递推，并检查安全和跨日连续性。

### 9.4 功率和互斥检验

\[
\frac{c_t}{\Delta t}\le5000,\qquad
\frac{d_t}{\Delta t}\le5000,
\]

\[
\min(c_t,d_t)\approx0.
\]

物理意义：确认单时段功率不超过 5000 kW，且没有无意义的同时充放电。

### 9.5 非预期性检验

对每一天检查：

1. \(g_t\) 是否只用前一天及以前的数据构造；
2. 6:00、12:00、18:00 的 \(q_t\) 是否只用该时刻以前的真实数据和预报；
3. 实时 \(c_t,d_t\) 是否只用截至 \(t\) 的数据和当前实际价格。

物理意义：避免模型利用未来真实值获得不可实现的“完美预测”收益。

### 9.6 费用一致性检验

分别计算：

\[
C_{\text{plan}}=\sum_t\pi_t^{\text{actual}}g_t,
\]

\[
C_{\text{adjust}}=\sum_t\pi_t^{\text{actual}}
\left(
1.5\Delta_t^++0.5\Delta_t^-
\right),
\]

\[
C_{\text{emergency}}=5\sum_t\pi_t^{\text{actual}}e_t,
\]

并要求输出费用等于三项之和。

物理意义：检查计划、调整、紧急三类费用没有遗漏、重复或符号错误。

### 9.7 基线对照检验

构造三个基线：

1. 无储能基线，\(c_t=d_t=0\)；
2. 固定电价基线，即原问题二、问题三使用附件 1 的结果；
3. 完全信息下界，假设实际负荷、实际光伏和实际价格全部已知后求解最小费用。

要求结果满足：

\[
K_{\text{perfect}}\le K_{4\text{-}2}\le K_{\text{no-storage}},
\]

并给出波动电价相对固定电价的费用变化和紧急购电变化。

物理意义：完全信息是理论下界，无储能是简单上界。若波动电价模型落在区间之外，说明模型目标、结算口径或约束实现存在问题。

### 9.8 情景与稳健性检验

采用样本外历史日进行滚动验证，比较预测费用与实际结算费用。可计算：

\[
\operatorname{MAE}
=
\frac1n\sum_{i=1}^n|y_i-\widehat y_i|,
\]

\[
\operatorname{MAPE}
=
\frac1n\sum_{i=1}^n
\left|\frac{y_i-\widehat y_i}{y_i}\right|
\times100\%.
\]

物理意义：检验价格和负荷光伏情景是否对真实偏差有足够的覆盖率。

### 9.9 灵敏度检验

对参数 \(\theta\) 定义相对灵敏度：

\[
S_\theta
=
\frac{\Delta K/K_0}{\Delta\theta/\theta_0}.
\]

至少检查：

1. 电价整体倍率；
2. 紧急购电倍数；
3. 储能效率 \(\eta\)；
4. 储能容量和初始 SOC；
5. 历史回看窗口；
6. 情景数量；
7. 终端价值系数 \(\lambda\)。

物理意义：如果某个参数发生小扰动时费用或购电量出现跳变，说明情景生成、动态规划或优化求解存在不稳定区域。

### 9.10 输出完整性检验

检查 `result4-2.xlsx` 和 `result4-3.xlsx`：

1. 包含 334 天、每天 144 个 10 分钟时段；
2. 工作表名称、顺序和列数与附件 5 模板一致；
3. 电量单位统一为 kWh，费用单位为元；
4. 紧急购电按连续时间段合并，且同一日期只首行写日期；
5. 无空值、重复日期、重复时段或越界 SOC。

物理意义：确保论文结果和提交文件完全符合题目要求，避免因格式错误失分。

### 9.11 结果合理性判断

1. 低价时段应倾向充电，高价时段应倾向放电；
2. 光伏高峰应出现充电或弃光，晚高峰应优先放电；
3. 紧急购电量不应长期接近零，也不应接近总负荷量；
4. 年末 SOC 不应无解释地贴在上限或下限；
5. 波动电价下模型应比固定电价模型更充分地利用价格峰谷差；
6. 增加情景数量、细化 SOC 网格时，结果应收敛而不是大幅跳变。

## 10. 结论

问题四的完整结构可以概括为：

\[
\boxed{
\text{附件4实时价格替换附件1固定价格}
}
\]

\[
\boxed{
\text{负荷、光伏、价格构造联合历史情景}
}
\]

\[
\boxed{
\text{4-2保持 }g_t\text{ 0:00锁定，储能实时响应}
}
\]

\[
\boxed{
\text{4-3保持 }g_t\text{ 0:00锁定、}q_t\text{ 三时点更新}
}
\]

\[
\boxed{
\text{优化用期望价格，实际结算用附件4真实价格}
}
\]

该模型在保留问题二、问题三原有决策结构的基础上，把电价从已知常数升级为随机情景和实际结算价格，使购电计划、调整购电和储能执行能够适应实时价格波动。
